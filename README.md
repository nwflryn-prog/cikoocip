# Cikoocip Profile Website

Sebuah website profil personal dengan desain glassmorphism modern dan animasi partikel interaktif.

## 🎨 Fitur

- ✨ Desain glassmorphism dengan backdrop blur
- 🎪 Animasi partikel floating di background
- 📱 Responsive design (mobile-friendly)
- 🎮 Link ke profil Roblox
- 💬 Link ke Discord server
- ❤️ Link untuk donasi
- 🎯 Smooth animations dan hover effects

## 📁 Struktur File

```
cikoocip/
├── index.html      # File HTML utama
├── style.css       # Styling dengan glassmorphism
├── script.js       # Animasi partikel canvas
├── logo.png        # Foto profil (opsional)
└── README.md       # Dokumentasi
```

## 🚀 Cara Menggunakan

1. Clone repository ini
2. Tambahkan file `logo.png` ke folder project (foto profil Anda)
3. Buka `index.html` di browser

## ⚙️ Kustomisasi

### Ganti Link
Edit di `index.html`:
- Roblox: Ganti URL di link Roblox
- Discord: Ganti URL invite Discord
- Donate: Ganti URL donasi

### Ganti Warna
Edit di `style.css`:
- Ubah warna tombol sesuai keinginan
- Modifikasi warna partikel di `script.js`

### Ganti Background
Edit di `style.css` bagian `.background` untuk menggunakan gambar lain.

## 📝 Teknologi

- HTML5
- CSS3 (Glassmorphism, Animations)
- JavaScript (Canvas API)
- Font Awesome Icons
- Google Fonts (Poppins)
